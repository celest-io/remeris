# Getting help

- **Questions** (how do I configure a workflow, why does this output look like this, is this the same as Knope): ask in
    [GitHub Discussions](https://github.com/celest-io/remeris/discussions), category Q&A. Your question helps the next person who searches.
- **Ideas and show and tell:** the same place, in the Ideas and Show and tell categories.
- **Bugs and feature requests:** open an [issue](https://github.com/celest-io/remeris/issues) with the form that matches. Search first, and read
    [docs/differences.md](docs/differences.md): remeris mirrors Knope, so the same behaviour is expected unless that page says otherwise.
- **Security problems:** do not use issues or discussions; follow [SECURITY.md](SECURITY.md).

Before you ask, the documentation may already answer it: [docs/usage.md](docs/usage.md), [docs/configuration.md](docs/configuration.md) and
[docs/differences.md](docs/differences.md). The behaviour of remeris comes from [Knope](https://github.com/knope-dev/knope), whose documentation also applies where remeris is a
drop-in replacement.

remeris is maintained by volunteers. There is no guaranteed response time.
